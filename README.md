# Electro Mobile App ⚡

A full-stack React Native / Expo mobile application for the Electro platform, featuring dual authentication, address management, and integrated Razorpay payments.

## Features 🚀
- **Dual Authentication**: Secure user login and registration.
- **Product Catalog & Browsing**: Explore and search electronic products seamlessly.
- **Address Management**: Save and manage delivery addresses.
- **Razorpay Integration**: Secure checkout and payment processing workflow.
- **Custom Splash Screens & Icons**: Tailored branding for Android and iOS.

## Tech Stack 🛠️
- **Frontend**: React Native, Expo, Expo Router
- **Backend Integration**: Next.js & MongoDB REST APIs
- **Payments**: Razorpay SDK

## Getting Started 💻

### Prerequisites
Make sure you have Node.js and the Expo CLI installed on your machine.

### Installation
1. Clone the repository:


git clone https://github.com/bublaisarkar/Electro-Mobile.git
cd Electro-Mobile

2. Install dependencies:


npm install


npx expo start As(s for native development)
